# 📝 Gestor de Tareas en React (JDP 2025)

Este proyecto es un **ejercicio integrador de React** desarrollado en el marco del **Junior Development Program 2025 (JDP)** de **ASAP** y la **UTN**.  
El trabajo fue realizado en el curso de **React** bajo la supervisión del profesor **Marcelo Bettini**.

👨‍💻 Autor: **Pedro Ricardo Herrera**

---

## 📌 Descripción

La aplicación es un **Gestor de Tareas** que permite:
- Crear tareas con título y descripción.
- Listar todas las tareas.
- Cambiar el estado de cada tarea (`pendiente`, `en proceso`, `terminada`).
- Eliminar tareas.

El objetivo del ejercicio es **practicar distintos métodos de manejo de estado en React**, implementando **tres versiones diferentes** de la misma aplicación.

---

## 🌳 Organización del repositorio

Este repositorio no cuenta con una rama `main`.  
En su lugar, cada rama corresponde a una implementación distinta:

- **`useState`** → Primera implementación, utilizando el hook `useState()`.
- **`useReducer`** → Segunda implementación, utilizando el hook `useReducer()`.
- **`redux`** → Tercera implementación, utilizando **Redux** para la gestión global del estado.

De esta forma, cada rama es totalmente independiente y contiene una versión completa del proyecto.
